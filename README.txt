Drop government / department logo images here (PNG, JPG or WEBP).
The file name becomes the caption, e.g.  WAPDA.png  ->  "WAPDA",
Government_of_Pakistan.png -> "Government of Pakistan".
Files appear in a strip on every page, in alphabetical order.
Prefix with numbers to control order: 01_Government_of_Pakistan.png, 02_WAPDA.png ...
